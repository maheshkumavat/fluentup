# FluentUp: GitHub Auto-Build & Over-The-Air Update Workflow

This document outlines the setup steps and day-to-day workflow for FluentUp's automated GitHub Actions CI/CD release pipeline and in-app update system.

---

## 1. Initial Setup: Create GitHub Repository & Push Code

### Step 1: Create GitHub Repository
1. Go to [GitHub New Repository](https://github.com/new).
2. Set **Repository name**: `fluentup` (or any preferred name).
3. Set Visibility: **Private** (recommended).
4. Do **NOT** check "Add a README file" or ".gitignore" (we already created them locally).
5. Click **Create repository**.

### Step 2: Push Local Code to GitHub
Run the following terminal commands inside your project folder:

```bash
git add .
git commit -m "Initial commit with CI/CD and update system"
git branch -M main
git remote add origin https://github.com/YOUR_GITHUB_USERNAME/fluentup.git
git push -u origin main
```
*(Replace `YOUR_GITHUB_USERNAME` with your actual GitHub username).*

---

## 2. Configure GitHub Actions Secrets

To enable automated release signing, add the following 4 secrets under **GitHub Repository → Settings → Secrets and variables → Actions → New repository secret**:

| Secret Name | Value to Paste | Description |
| :--- | :--- | :--- |
| **`KEYSTORE_BASE64`** | *(Contents of `keystore_base64.txt`)* | Base64 string of `upload-keystore.jks` generated by `keytool`. |
| **`KEYSTORE_PASSWORD`** | `<your_keystore_password>` | Password for the release keystore. |
| **`KEY_ALIAS`** | `upload` | Key alias name inside the keystore. |
| **`KEY_PASSWORD`** | `<your_key_password>` | Password for the key alias. |

> **Note**: `keystore_base64.txt` is located in your project root and is excluded from git for security.

## 3. Day-to-Day Development Workflow

Once setup is complete, you never need a laptop USB cable or manual `flutter install` again:

1. **Make Code Changes**: Edit code as usual.
2. **Commit and Push**:
   ```bash
   git add .
   git commit -m "Add new feature or fix"
   git push origin main
   ```
3. **Automated Cloud Build**:
   - GitHub Actions automatically triggers on push to `main`.
   - It builds a signed release APK (`FluentUp-v1.0.0+X.apk`) and publishes a new release on GitHub.
4. **Over-The-Air Update on Device**:
   - Open FluentUp on your phone.
   - The app automatically detects the new GitHub release tag and presents a styled **"UPDATE AVAILABLE"** bottom sheet.
   - Tap **Update Now** — the app downloads the APK in-app with a progress indicator and prompts Android's 1-tap package installer!

---

## 4. Troubleshooting & Notes

- **Android "Install Unknown Apps" Prompt**: On the very first in-app update, Android will ask permission to allow FluentUp to install apps. Toggle "Allow from this source" once, and future updates will install seamlessly.
- **Manual Update Check**: You can also check for updates anytime on the **Profile Screen → Check for Updates**.
